### Codes for ruled based reconciliation

    wikidata.csv
Data dump from wikidata containing > 5.200.000 person entries. The data columns include IDs, preferable fullname, gender, years of birth and death, and ULAN identified.

    ulan.csv
Data dump from Getty Union List of Artist Names containing > 290.000 person entries. The data columns include IDs, preferable fullname, gender, years of birth and death, and Wikidata identified.
