# Overview

Work Package 4 (**WP4**) of the ECHOLOT project delivers AI-assisted, human-in-the-loop workflows for processing Cultural Heritage (CH) data. These workflows combine automated processing (e.g., AI, knowledge-based, rule-based methods) with human expertise to enable efficient, reliable, and scalable curation of CH datasets for:

- Data transformation (import/export, format/model mappings).
- Entity reconciliation (linking to external knowledge bases like Wikidata).
- Data enrichment (LLM-based entity recognition, summarization, multilingual alignment).
- Advanced image recognition (3D models, videos, born-digital art).
- Automated quality checks (schema validation, SHACL, completeness checks).

This repository contains some of the source code, documentation, and configurations for WP4’s hybrid curation workflows.
In some cases, where appropriate,  the source code is stored in dedicated repositories.
